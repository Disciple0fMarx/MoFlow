# LOSO Visualizations (ETH/UCY)

This directory is prepared for trajectory visualizations and Grad-CAM heatmaps from all 15 LOSO runs.
- Trajectories: GT vs predicted multimodal trajectories (K=20) overlaid in world coordinates with homography validation
- Grad-CAM: ResNet-18 layer4 heatmaps for static/full modes

Kaggle kernel v17/v18 attempts ran but checkpoints were not found in expected locations on Kaggle; artifacts will be added when regenerated with checkpoints synced.
